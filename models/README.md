# models

Reserved for local model artefacts used by later phases (e.g. the handwriting
style classifier exported to ONNX in Phase 5). No model binaries exist in
Phase 0 - none are downloaded, generated, or committed.

`checksums.json` will record reproducible checksums for any model file once real
models are introduced. It is intentionally empty in Phase 0.

Do not commit placeholder or fake model binaries.
