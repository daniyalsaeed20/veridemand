# Remediation evaluation schemas

**EVALUATION SCHEMA — NOT YET PRODUCTION CONTRACT**

Files in this directory support Remediation Part 1 acceptance tooling only.

They must not be treated as replacements for `docs/contracts/` production entities (`SourceToken`, `SourceSpan`, etc.).

Promoting any evaluation schema into production requires an explicit contract change and phase gate — not Part 1.

## Schemas

| File | Role |
|------|------|
| `extraction-result-eval.schema.json` | Vendor-neutral engine result for scoring |
| `page-annotation.schema.json` | Human page annotation for the localhost review app |
