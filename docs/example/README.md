# Local case samples (not committed)

This directory may hold **local-only** reference material during development.

- Do **not** place private medical records, client PDFs, or case documents here.
- Private regression documents belong only under gitignored `fixtures/private/`.
- Document binaries (`*.pdf`, `*.docx`, `*.doc`, images) under `docs/example/` are
  gitignored and must never be staged or committed.
- Shareable synthetic fixtures live under `fixtures/synthetic/` (and related
  synthetic trees), never here.

If you need a placeholder folder for notes, keep markdown only.
